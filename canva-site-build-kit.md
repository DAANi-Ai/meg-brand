# Megan O'Byrne — Canva Site Build Kit

Everything needed to rebuild the website inside Canva Sites, so Meg can edit and republish it herself with no gatekeeper. Build it once in Canva, hit Publish, and every future tweak is Meg's to make.

How to start: Canva home, Create a design, search "Website", pick a scrolling one-page layout. Build the sections below top to bottom. When done, Share, then Publish website (free Canva subdomain, or connect a custom domain).

---

## Brand setup (do this first, in Canva Brand Kit)

Colours (add all five to the Brand Kit):
- Cream `#FAF2E9` — page background
- White `#FFFFFF` — cards and clean space
- Pink `#FFBBDA` — accent, soft bands, photo frames, small highlights
- Black `#000000` — all text, buttons
- Grey `#575757` — captions and secondary text

No yellow, orange or sunset tones anywhere.

Fonts:
- Headings: Agrandir Grand Bold
- Name and emphasised words: Brittany (signature script)
- Body text: Montserrat

Note on fonts in Canva: Montserrat is built in. Agrandir Grand Bold and Brittany are licensed fonts, so upload their files under Brand Kit, Fonts, Upload a font (needs Canva Pro). If a font is not to hand yet, the closest Canva built-ins are a heavy grotesque (e.g. Archivo, Anton) for Agrandir and a clean signature script (e.g. Beau Rivage, Sail) for Brittany, swapped later.

Buttons: black fill, white Montserrat 600 text, fully rounded (pill) corners.

## Two things to keep it on-brand in Canva

1. Black text on light backgrounds, always. Pink and cream are for fills, never for type.
2. Use Brittany only for the name and the odd emphasised word. Everything else is Agrandir (headings) and Montserrat (body).
